# Dokumentasi SIMAS

Indeks dokumentasi proyek SIMAS (Sistem Informasi Manajemen Absensi Siswa).

| Berkas | Isi |
| --- | --- |
| [`SIMAS_Blueprint_PRD_ERD_SRS.md`](SIMAS_Blueprint_PRD_ERD_SRS.md) | Dokumen induk: PRD, ERD, SRS, aturan bisnis, design system, rencana tahapan, dan definisi "siap dipamerkan". |
| [`IMPLEMENTATION-STATUS.md`](IMPLEMENTATION-STATUS.md) | Status pelaksanaan per tahap, ERD aktual, penyimpangan yang disengaja, dan strategi pengujian yang dijalankan. |
| [`../README.md`](../README.md) | Instalasi dari awal, akun demo, aturan bisnis, cara menjalankan test, dan troubleshooting. |

## Cara membaca

1. Mulai dari **README** bila tujuan Anda menjalankan aplikasi.
2. Lanjut ke **IMPLEMENTATION-STATUS** untuk mengetahui apa yang sudah
   diimplementasikan dan keputusan teknisnya.
3. Gunakan **Blueprint** sebagai rujukan kebutuhan produk, rancangan data, dan
   kriteria penerimaan.

## Catatan

Blueprint asli sengaja tidak diduplikasi menjadi berkas terpisah
(`PRD.md`, `ERD.md`, `SRS.md`, `UI-UX.md`, `IMPLEMENTATION-PLAN.md`) karena
dokumen induk sudah memuat seluruh bagian tersebut secara lengkap dan
konsisten. Sesuai arahan pada blueprint §9, pendekatan yang diambil adalah
**melengkapi** dengan dokumen status implementasi, bukan menyalin isi yang
sudah ada.
